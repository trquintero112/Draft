      Source Strategy

      This static GitHub version ships with a 2026 seed board and lets you import rankings from FantasyPros, ESPN, RotoBaller, Draft Sharks, CBS/SportsLine, Footballguys, Yahoo, Sleeper exports, or your own sheet as CSV. Browser security/CORS and paid-site terms usually prevent a GitHub Pages site from scraping those sites automatically, so this version is designed for clean source imports plus full local persistence.

      • Use Import CSV to add or overwrite rankings from another site.
      • Edit any row directly with the Rank/Tier buttons.
      • Select Mine when you draft a player, or Gone when another manager drafts him.
